# InternTrack

InternTrack is a full-stack internship application tracking web application built with Python, Flask, SQLite, HTML and CSS.

## Features

- Add internship applications
- Edit application information
- Delete applications
- Track application status
- Filter applications by status
- Sort applications by application date
- Pagination with 5 applications per page
- Dashboard statistics
- Responsive dark-green user interface
- SQLite database persistence

## Technologies

- Python
- Flask
- SQLite / SQL
- HTML
- CSS
- Jinja
